C++ STL / algorithm Cheatsheet

手撕代码与力扣题目高频操作 · C++17 · 代码默认 using namespace std

看到“有序数组”优先想 sort + lower_bound；看到“动态最值”优先想 priority_queue；删除连续值使用 erase(remove(...))。

题目模板 · 直接开写

#include <algorithm> // sort, find, lower_bound, ... #include <numeric> // accumulate, iota, gcd, ... #include <queue> // queue, priority_queue这页高频函数的主要头文件；vector、map、set 等容器也可单独包含对应头文件
using namespace std; using ll = long long;减少题目代码噪声；数值可能溢出 int 时使用 long long
ios::sync_with_stdio(false); cin.tie(nullptr);关闭 C/C++ 流同步并解除绑定，输入量大时常用
for (auto &x : v) { /* x 可修改 */ } for (const auto &x : v) { /* 只读 */ }范围 for；不需要下标时最简洁
auto [a, b] = p; auto [it, inserted] = s.insert(x);结构化绑定，拆 pair 或函数返回值

vector · 动态数组

vector<int> v; vector<int> v(n); vector<int> v(n, value);空数组、长度为 n 的零初始化数组、填充值数组
v.size(); v.empty(); v.front(); v.back(); v[i];长度、判空、首尾元素和下标访问
v.push_back(x); v.pop_back();尾部增删；访问或删除前先确认非空
v.insert(v.begin() + i, x);在位置前插入一个元素，返回插入位置迭代器
v.erase(v.begin() + i); v.erase(v.begin() + l, v.begin() + r);删除单个元素或半开区间 [l, r)；返回下一个有效迭代器
v.resize(n);改变元素个数；新增加的元素使用默认值
v.clear();清空全部元素；容量通常保留
v.erase(remove(v.begin(), v.end(), x), v.end());删除所有等于 x 的元素；remove 只搬移，必须配合 erase

string · 字符串

string s = "abc"; string s(n, 'x'); getline(cin, s);构造字符串；getline 读取包含空格的一整行
s.size(); s.empty(); s[i]; s += t; s.push_back(c);长度、访问、拼接和追加字符
s.substr(pos, len); s.find("abc"); s.find('x') == string::npos;截取、查找；未找到时返回 string::npos
s.erase(pos, len); s.insert(pos, "abc");按位置删除或插入；省略 len 可删除到末尾
stoi(s); stoll(s); to_string(x);字符串与整数/长整数互转；输入保证格式正确时最方便

stack / queue

stack<int> st; st.push(x); st.top(); st.pop();后进先出；pop 只删除，不返回元素
queue<int> q; q.push(x); q.front(); q.pop();先进先出；BFS、拓扑排序常用

priority_queue · 堆

priority_queue<int> pq; pq.push(x); pq.top(); pq.pop();默认大根堆；top 是当前最大值，插入/删除为 O(log n)
priority_queue<int, vector<int>, greater<int>> pq;小根堆；第三模板参数是比较器
using P = pair<int, int>; priority_queue<P, vector<P>, greater<P>> pq;对 pair 建小根堆：先比较 first，再比较 second

set · 有序集合

set<int> s; s.insert(x); s.erase(x);set 去重且自动升序；按值插入或删除
auto it = s.find(x); if (it != s.end()) { ... }查找元素；未找到时返回 end
auto it = s.lower_bound(x); auto jt = s.upper_bound(x);lower_bound 找首个 >= x；upper_bound 找首个 > x

map / unordered_map · 键值表

map<string, int> mp; mp[key]++;map 按键有序；operator[] 不存在时会先插入默认值，计数最常用
if (auto it = mp.find(key); it != mp.end()) { ... }查找键是否存在；未找到时返回 end
mp.erase(key);按键删除；不存在时不报错

sort · 排序

sort(v.begin(), v.end()); sort(v.begin(), v.end(), greater<int>{});升序/降序排序，平均 O(n log n)；默认不保证相等元素相对顺序
sort(a.begin(), a.end()); sort(a.begin(), a.end(), [](const auto &x, const auto &y) { return x.second < y.second; });二维数组、pair、结构体都可直接传 lambda

binary search · 二分查找

auto it = lower_bound(v.begin(), v.end(), x); int pos = it - v.begin();首个 >= x 的位置；不存在时为 end，常用于插入点
auto it = upper_bound(v.begin(), v.end(), x); int pos = it - v.begin();首个 > x 的位置；有序数组中 x 的个数为 upper - lower
lower_bound/upper_bound 要求区间已按同一规则排序；随机访问容器才能用迭代器相减得到下标。

min / max / element

min(a, b); max(a, b);取两个值中的最小/最大值；多个值可嵌套调用
auto it = min_element(v.begin(), v.end()); auto jt = max_element(v.begin(), v.end());返回最小/最大元素迭代器；空区间不要解引用
swap(a, b);交换两个值；交换容器或变量时直接使用

reverse / unique

reverse(v.begin(), v.end());原地反转整个区间
sort(v.begin(), v.end()); v.erase(unique(v.begin(), v.end()), v.end());数组去重的标准写法；结果仍保持升序
v.erase(remove(v.begin(), v.end(), x), v.end());删除所有等于 x 的元素；remove 必须配合 erase

fill · 区间填充

fill(v.begin(), v.end(), x);把区间所有元素设为同一个值

find / count · 条件查找

count(v.begin(), v.end(), x); count_if(v.begin(), v.end(), pred);统计等于某值或满足谓词的元素个数
auto it = find(v.begin(), v.end(), x); auto jt = find_if(v.begin(), v.end(), pred);寻找首个匹配元素；未找到返回 end

<numeric> · 题目里的数值工具

iota(v.begin(), v.end(), 0);从起始值开始连续填充：0, 1, 2, ...；下标初始化很方便
accumulate(v.begin(), v.end(), 0LL);求和；初值写 0LL 防止 int 溢出
gcd(a, b); lcm(a, b);C++17 最大公约数与最小公倍数；需 <numeric>
