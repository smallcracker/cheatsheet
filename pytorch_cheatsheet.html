PyTorch Cheatsheet

深度学习框架常用指令参考 v2.x

张量创建 (Tensor Creation)

torch.tensor([1, 2, 3]) 从列表数据直接创建张量
torch.zeros(2, 3) 创建全 0 张量 (2行3列)
torch.ones(2, 3) 创建全 1 张量
torch.rand(2, 3) [0, 1) 均匀分布随机数
torch.randn(2, 3) 标准正态分布随机数 (均值0, 方差1)
torch.arange(0, 10, 2) 范围创建 [start, end) 步长2
torch.linspace(0, 1, 100) 在区间内均匀生成 100 个点
torch.eye(3) 创建 3x3 单位矩阵
torch.full((2, 3), 9) 创建全为 9 的张量

属性与转换 (Attributes)

t.shape / t.size() 获取张量形状 (Size对象)
t.dtype 获取数据类型 (如 torch.float32)
t.device 查看所在设备 (cpu / cuda:0)
t.item() 获取单元素张量的 Python 数值
t.numpy() 转 NumPy 数组 (需在CPU上)
torch.from_numpy(arr) NumPy 转 Tensor (共享内存)
t.to("cuda") / t.cuda() 移动到 GPU
t.to("cpu") / t.cpu() 移动到 CPU
t.float() / t.long() 类型转换 (float32 / int64)

形状操作 (Shape Ops)

t.view(shape) 改变形状 (数据需内存连续)
t.reshape(shape) 改变形状 (通用, 可能会复制)
t.transpose(0, 1) 交换两个维度 (转置)
t.permute(0, 2, 1) 重新排列所有维度
t.squeeze(dim) 去除指定的大小为 1 的维度
t.unsqueeze(dim) 在指定位置增加大小为 1 的维度
torch.cat([t1, t2], dim=0) 沿指定维度拼接张量
torch.stack([t1, t2], dim=0) 沿新维度堆叠张量
t.flatten(start_dim=1) 展平张量 (常用于全连接层前)

数学运算 (Math)

t1 + t2 元素加法 (支持广播机制)
t1 * t2 元素乘法 (Hadamard product)
t1 @ t2 / t1.matmul(t2) 矩阵乘法
t.sum(dim, keepdim=False) 求和
t.mean(dim) 求平均值
t.max(dim) 求最大值 (返回 values 和 indices)
t.argmax(dim) 求最大值的索引
torch.clamp(t, min, max) 数值截断 (夹逼)

神经网络层 (torch.nn)

nn.Linear(in_ft, out_ft) 全连接层 (Linear Layer)
nn.Conv2d(in_c, out_c, k_size) 2D 卷积层
nn.MaxPool2d(kernel_size) 最大池化
nn.BatchNorm2d(num_features) 批标准化 (Batch Norm)
nn.Dropout(p=0.5) 随机失活 (防过拟合)
nn.ReLU() / nn.Sigmoid() 常用激活函数
nn.Softmax(dim=1) 归一化概率分布
nn.Embedding(num, dim) 词嵌入层
nn.Sequential(...) 顺序容器，快速搭建模型

训练流程 (Training Loop)

criterion = nn.CrossEntropyLoss() 定义损失函数 (分类常用)
optimizer = optim.Adam(model.parameters(), lr=0.001) 定义优化器 (Adam)
optimizer.zero_grad() 1. 清空旧梯度
output = model(inputs) 2. 前向传播 (Forward)
loss = criterion(output, target) 3. 计算损失 (Loss)
loss.backward() 4. 反向传播 (Backward)
optimizer.step() 5. 更新参数 (Update)

自动求导 (Autograd)

x.requires_grad = True 标记张量需要追踪梯度
y.backward() 计算梯度 (默认存入 .grad)
x.grad 查看累积的梯度值
with torch.no_grad(): 上下文: 停止梯度计算 (推理/评估时用)
x.detach() 返回一个从计算图分离的新张量
x.grad.zero_() 手动清空梯度

数据处理 (Data)

class MyDataset(Dataset): 继承 Dataset，实现 __len__, __getitem__
DataLoader(dataset, batch_size=32, shuffle=True) 构建数据加载器 (批处理、打乱)
inputs, labels = next(iter(loader)) 获取一个 Batch 的数据
torchvision.transforms 常用图像预处理 (Resize, ToTensor)

保存与加载 (Save/Load)

torch.save(model.state_dict(), 'w.pth') 仅保存模型参数 (推荐)
model.load_state_dict(torch.load('w.pth')) 加载模型参数
torch.save(model, 'model.pth') 保存整个模型 (结构+参数)
model = torch.load('model.pth') 加载整个模型
model.train() 训练模式 (启用 Dropout/BatchNorm)
model.eval() 评估模式 (禁用 Dropout/BatchNorm)

实用技巧 (Tips)

torch.manual_seed(42) 设置随机种子 (复现性)
if torch.cuda.is_available(): 检查 GPU 是否可用
torch.cuda.device_count() GPU 数量
nn.functional.softmax(x, dim=1) 函数式接口 (无状态层)
t.clone() 深拷贝张量 (记录梯度历史)
torch.set_printoptions(precision=4) 设置打印精度

维度操作图解

dim=0 行方向 (向下压缩) / 批次维度
dim=1 列方向 (向右压缩) / 特征/通道维度
keepdim=True 保持聚合后的维度为 1，便于广播
None / [None, :] Numpy风格增加维度 (=unsqueeze)
