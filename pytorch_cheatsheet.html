PyTorch Cheatsheet

张量创建 (Tensor Creation)

torch.tensor(data, dtype=None, device=None) 用列表数据创建张量，总是创建一个新的拷贝
要使用torch.tensor，不使用torch.Tensor
torch.tensor能自动推断数据类型
可输入元组，列表，numpy数组，标量，布尔值，其他张量
初始化梯度为0
torch.as_tensor(data, dtype=None, device=None) 尽量零拷贝构造张量 (可指定类型和设备)，稍微快一点
Shares memory with the input if possible
保留过去的梯度信息
注意，因为可能共享内存，所以一改全改！修改原本的ndarray也会导致tensor改变！
empty = torch.tensor(()) 创建空张量，不初始化
empty_err = torch.tensor()会报错
torch.zeros(2, 3) 创建全 0 张量 (2行3列)
torch.ones(2, 3) 创建全 1 张量
torch.empty(2, 3) 创建未初始化张量 (占位更快)
torch.zeros_like(t) 按已有张量形状创建全 0
torch.ones_like(t) 按已有张量形状创建全 1
torch.randn(2, 3) 标准正态分布随机数 (均值0, 方差1)
torch.randint(0, 10, (2, 3)) 整数随机张量 (区间 [0, 10))
torch.arange(0, 10, 2) 范围创建 [start, end) 步长2
torch.full((2, 3), 9) 创建全为 9 的张量

属性与转换 (Attributes)

t.shape / t.size() 获取张量形状 (Size对象)
t.dtype 获取数据类型 (如 torch.float32)
torch.float32 = torch.float
torch.float64 = torch.double
torch.bfloat16 : SEM=1-8-7
torch.int64 = torch.long
torch.int32 = torch.int
torch.uint8
torch.bool 常用 dtype 常量
torch.FloatTensor / torch.LongTensor 旧式类型构造器，参数反直觉，不推荐使用
t.device 查看所在设备 (cpu / cuda:0)
torch.device("cuda:0") 显式创建设备对象
t.item() 获取单元素张量的 Python 数值
t.numpy() 转 NumPy 数组 (需在CPU上)
torch.from_numpy(arr) NumPy 转 Tensor (共享内存)
torch.is_tensor(x) 判断对象是否为 Tensor
t.to("cuda") / t.cuda() 移动到 GPU
t.to("cpu") / t.cpu() 移动到 CPU
t.float() / t.long() 类型转换 (float32 / int64)

形状操作 (Shape Ops)

t.view(shape) 改变形状 (数据需内存连续)
t.reshape(shape) 改变形状 (通用, 可能会复制)
t.transpose(0, 1) 交换两个维度 (转置)
t.permute(0, 2, 1) 重新排列所有维度
t.squeeze(dim) 去除指定的大小为 1 的维度
如果dim是None，则去除所有大小为 1 的维度
如果这个维度大小不是1，则不改变
如果向量本身的尺寸是[1]，则会有unexpected errors
不重新分配内存！！
t.unsqueeze(dim) 在指定位置增加大小为 1 的维度
torch.cat([t1, t2], dim=0) 沿指定维度拼接张量
拼接过程不产生新的维度，只是扩充已有维度的大小
除了需要拼接的那个维度，其他维度的大小必须相同
torch.stack([t1, t2], dim=0) 沿新维度堆叠张量
需要输入shape相同的几个张量
产生新的维度，有几个张量，新的维度的大小就是几
torch.split(t, split_size_or_sections, dim=0) 按指定大小或段数切分
如果split_size_or_sections是int，则按大小切分，最后一段可能小于指定尺寸
如果split_size_or_sections是list，则按段数切分，list里的数字加起来必须等于这个维度的大小
输出的划分结果是个元组
torch.chunk(t, chunks, dim=0) 平均切分为若干块
试图将输入张量沿着指定维度平均切分为chunks块
如果不能整除，则最后一块会小于其他块
返回的chunk数量可能小于指定数量
输出的是一个元组
t.flatten(start_dim=1) 展平张量 (常用于全连接层前)
start_dim是开始展平的维度，之前的维度保持不变

数学运算 (Math)

t1 + t2 元素加法 (支持广播机制)
t1 * t2 元素乘法 (Hadamard product)
t1 @ t2 / t1.matmul(t2) 矩阵乘法
t.sum(dim, keepdim=False) 求和
t.mean(dim) 求平均值
t.max(dim) 求最大值 (返回 values 和 indices)
t.argmax(dim) 求最大值的索引
torch.where(cond, a, b) 按条件选择元素，类似三目运算符
cond是条件，a是True时的值，b是False时的值
返回的是一个张量，形状与cond相同
torch.equal(a, b)
torch.all(a == b) 张量整体相等判断
torch.linalg.norm(t, dim=-1, ord=2) 向量或矩阵范数
dim是一个整数的话，就是求向量L2范数
dim是一个2-tuple的话，就是求矩阵的Frobenius范数
dim和ord都缺省的话，就是展平求向量L2范数
dim=-1就是求最后一维的范数
torch.exp(t)
torch.log(t) 指数与对数
torch.min(t, dim) 求最小值 (返回 values 和 indices)
torch.tanh(t) 双曲正切激活
torch.clamp(t, min, max) 数值截断 (夹逼)

神经网络层 (torch.nn)

self.xxx = nn.*
或 nn.ModuleList
或 nn.ModuleDict
或使用 register_module 注册：只需要将子模块赋值给父模块的属性即可
可见：已注册子模块会被 parameters()、state_dict()、to()、train()/eval() 等统一遍历；普通 list/dict 里的层不会注册，优化器与设备迁移也看不到。
class Net(nn.Module): 自定义模型基类
nn.Linear(in_ft, out_ft) 全连接层 (Linear Layer)
nn.Sequential(...) 顺序容器，快速搭建模型
输入一系列子模块，或者 OrderedDict of name-module pairs
nn.ModuleList([...]) / nn.ModuleDict({...}) 模块集合容器 用来容纳子模块的List和Dict
nn.Parameter(torch.zeros(...)) 输入一个tensor，得到可训练的tensor
包装的目的是将tensor注册为模型参数，能被优化器自动更新
默认requires_grad=True，表示在反向传播时自动计算梯度
model.parameters() 得到一个迭代器，迭代器中包含所有可训练的参数
可以用来遍历参数，可以传入优化器
nn.LayerNorm(normalized_shape) 层归一化：在单个样本的每个特征层上进行归一化，然后在进行缩放和平移
normalized_shape是归一化的维度，需要是input_shape的后缀
nn.Dropout(p=0.1) 随机失活 (防过拟合)
nn.GELU() / nn.SiLU() / nn.Tanh() / nn.ReLU() 常用激活函数
nn.Embedding(num, dim) 词嵌入层
nn.Identity() 恒等映射占位层
nn.TransformerDecoderLayer(d_model, nhead) Transformer 解码层
nn.DataParallel(model) 单机多卡数据并行

训练流程 (Training Loop)

criterion = nn.CrossEntropyLoss() 定义损失函数 (分类常用)
optimizer = optim.Adam(model.parameters(), lr=0.001) 定义优化器 (Adam)
optimizer = optim.AdamW(model.parameters(), lr=0.001) 定义优化器 (AdamW)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=1000) 学习率调度器
optimizer.zero_grad() 1. 清空旧梯度
output = model(inputs) 2. 前向传播 (Forward)
loss = criterion(output, target) 3. 计算损失 (Loss)
loss.backward() 4. 反向传播 (Backward)
optimizer.step() 5. 更新参数 (Update)
scheduler.step() 6. 更新学习率

自动求导 (Autograd)

x.requires_grad = True 标记张量需要追踪梯度
y.backward() 计算梯度 (默认存入 .grad)
x.grad 查看累积的梯度值
with torch.no_grad(): 上下文: 停止梯度计算 (推理/评估时用)
x.detach() 返回一个从计算图分离的新张量 (常用于截断反向传播)
x.detach().cpu().numpy() 将带梯度的张量转为 NumPy 数组 (常用组合)
x.grad.zero_() 手动清空梯度

保存与加载 (Save/Load)

torch.save(model.state_dict(), 'w.pth') 仅保存模型参数 (推荐)
model.load_state_dict(torch.load('w.pth')) 加载模型参数
model1.load_state_dict(model2.state_dict()) 在模型间复制参数 (常用于目标网络更新)
for p_tgt, p in zip(target.parameters(), net.parameters()): p_tgt.data.copy_(p_tgt.data * (1 - tau) + p.data * tau) 目标网络软更新 (Soft Update)
torch.save(model, 'model.pth') 保存整个模型 (结构+参数)
model = torch.load('model.pth') 加载整个模型
model.train() 训练模式 (启用 Dropout/BatchNorm)
model.eval() 评估模式 (禁用 Dropout/BatchNorm)

概率分布 (Distributions)

from torch.distributions import Categorical 导入类别分布 (常用于强化学习离散动作)
dist = Categorical(logits=logits) 根据 logits (未归一化概率) 创建分布
action = dist.sample() 按概率采样动作
log_probs = dist.log_prob(actions) 计算动作的对数概率 (actions 必须是 torch.long)
entropy = dist.entropy() 计算分布的熵 (常用于鼓励探索)

维度操作图解

dim=0 行方向 (向下压缩) / 批次维度
dim=1 列方向 (向右压缩) / 特征/通道维度
keepdim=True 保持聚合后的维度为 1，便于广播
None / [None, :] Numpy风格增加维度 (=unsqueeze)
